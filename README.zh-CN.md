# HA Tray

Home Assistant 的 Windows 托盘小工具。点通知区域的图标，任务栏上方会弹出 HA 的仪表盘，像 Win11 的快速设置面板；点别处就自动收起。

- 面板里显示的就是 HA 自己的网页，所有卡片都能用，包括 HACS 装的自定义卡片。面板上放什么，在 HA 自带的仪表盘编辑器里改。
- 给面板建一个仪表盘，每个房间一个视图，视图标签就是切房间的地方。
- 点面板顶栏右边的星标，把当前房间设为默认。面板每次收起后都会切回这个房间，下次一打开就是它。
- 面板尺寸固定，在设置里改。顶栏只留房间标签，HA 自己的菜单按钮都藏起来了。
- 主题色跟随 Windows 的强调色。
- 网页常驻在后台，所以点开就有。
- 指向其他网站的链接会用默认浏览器打开。

## 要求

- Windows 10 19041 及以上（推荐 Win11）
- Microsoft Edge WebView2 运行时（Win11 自带）
- .NET 10 桌面运行时

## 使用

第一次运行会弹出设置窗口，填 HA 地址（如 `http://homeassistant.local:8123`），点「保存」。然后打开面板，在里面登录一次 HA。登录状态保存在 `%LOCALAPPDATA%\HaTray\WebView2`，之后不用再登。

右键托盘图标可以：

- 编辑面板：用浏览器打开当前页面，直接进入仪表盘编辑模式；
- 把当前页面设为默认页面；
- 刷新页面，或在浏览器中打开当前页面；
- 打开设置（地址、默认页面、面板尺寸）、设置开机启动、退出。

Win11 可能把新出现的托盘图标收进「^」里。想让它一直显示，可以把图标拖到任务栏上，或者在「设置 → 个性化 → 任务栏 → 其他系统托盘图标」里把它打开。

## 构建

需要 .NET 10 SDK：

```
dotnet build src\HaTray -c Release -p:Platform=x64
```

开发时可以加参数：

- `--show`：启动后直接弹出面板，失焦也不收起。
- `--debug`：监视 `%LOCALAPPDATA%\HaTray\debug-eval.js`，文件一改就在面板网页里执行其中的 JS，结果连同窗口状态写进 `debug-result.json`。
